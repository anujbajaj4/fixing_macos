## What these numbers mean

- Every install or update downloads the .dmg once: the Terminal command, the in-app updater and a browser download all count.
- They're a lower bound for people (one person can install several times) and an upper bound for new users.
- They include test downloads by the author. Copies shared by AirDrop or a USB stick aren't counted.
- The raw numbers are in `downloads.csv`.
